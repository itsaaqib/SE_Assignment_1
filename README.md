# CSC3109 Assignment 1 — Custom APIs

Three independently runnable projects are in the task folders. Use Python 3 and VS Code. Each task folder has its own README and commands. Task 1 uses SQLite as required by the assignment (no MySQL needed); Tasks 2–3 use in-memory demo data.

## Suggested submission checklist
- Create a public GitHub repository and upload these three folders.
- Add a short screen-recording demonstration to each task folder or provide its public video link.
- Make a text file named `repository_link.txt` containing only your public repository URL.
- Task 2: never commit API keys or show them in a public video. Generate keys locally and share only privately with testers.
- Task 3 uses example classroom credentials; change them before sharing publicly.

Run servers from their respective folders in separate terminals. For Task 1, run Flask and Streamlit in two terminals. The README in each folder has the commands and tests.
